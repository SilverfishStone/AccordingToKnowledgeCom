This page is only for the site's author. Connect with a GitHub token that has write access to the site's repository. Without one, nothing can be saved or published.

How do I get a token?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories, and pick this site's repo.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else is needed.
  4. Set an expiry, generate, and paste the token above.

The token is kept in this browser only, and is sent to api.github.com and nowhere else. Untick "Remember me" on a shared computer, and use Disconnect in the ⋯ menu when you're done.
