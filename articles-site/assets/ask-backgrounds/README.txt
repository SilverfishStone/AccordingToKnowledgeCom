BACKGROUNDS FOR THE ANONYMOUS-MESSAGE PICTURES
===============================================

Every picture in this folder shows up in the "Background" list when you press
"Make image" on a message in /admin (accordingtoknowledge.com/admin).

TO ADD ONE
  1. Make a picture 1080 x 1920 pixels (tall, 9:16). PNG, JPG or WebP.
     Open _template-guide.png to see the size and which part a SQUARE
     picture uses (only the middle 1080 x 1080).
  2. Drop it in this folder.
  3. Commit and push (GitHub Desktop). The list updates on its own when the
     site rebuilds. There is no list to edit.

NAMES
  - The name becomes the label: "christmas.jpg" -> "Christmas",
    "4th-of-july.png" -> "4th of july".
  - Use only letters, numbers, spaces, dashes and underscores. Start with a
    letter or number.
  - Pictures show in A-Z order. Put a number first to reorder them:
    "01-christmas.jpg" -> still labelled "Christmas".
  - A file whose name starts with _ is not offered (like _template-guide.png).

TIPS
  - The message card sits in the middle, and the web address is written near
    the bottom edge, so keep the middle and the bottom calm.
  - A picture that is a different shape is scaled to cover and cropped to fit.
  - In /admin you can darken a picture so the text is easier to read, and pick
    the header colours and a light or dark card.
  - Keep each file under a few MB so the page stays quick.

STARTERS INCLUDED
  Christmas, Thanksgiving, Halloween, New Year's, Valentine's Day,
  St. Patrick's Day, Easter, Independence Day. Delete or replace any of them.
